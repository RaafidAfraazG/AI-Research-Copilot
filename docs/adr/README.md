# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the AI Research Copilot project.

ADRs capture important architectural decisions, the context that led to them, and the consequences.

## Index

| ADR | Title | Status |
|---|---|---|
| [001](./001-technology-choices.md) | Core Technology Stack Selection | Accepted |

## Format

Each ADR follows this structure:
- **Title**
- **Status**: Proposed | Accepted | Deprecated | Superseded
- **Context**: What situation prompted this decision?
- **Decision**: What was decided?
- **Consequences**: What are the results, tradeoffs, and implications?
